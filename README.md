# Files

Files is the read-only file explorer for Möbius. It provides a compact folder
list on phones and a browse-and-preview layout on larger screens.

The app can:

- move through the owner-visible app, shared, and platform folders;
- filter the current folder;
- preview text, images, audio, video, and PDFs; and
- download a selected file.

It deliberately does not edit, create, rename, move, or delete files. Project
work and code changes belong in Projects and agent chats.
